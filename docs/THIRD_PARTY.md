# Third-party components

The root license covers this project's code. Dependencies retain their own licenses; their source and notices are available through the committed Go, npm, and Cargo dependency manifests and lockfiles.

The public brand mark and favicon are simple project-authored SVG geometry. No original installation artwork, financial screenshots, or raster assets are bundled.

The frontend bundles IBM Plex Sans and Spectral through `@fontsource` packages (SIL Open Font License) and Phosphor icon fonts through `@phosphor-icons/web` (MIT). Preserve the dependency license files when redistributing built distributions. No private font or image collection is included.

Clerk and Plaid are third-party services requiring independently configured accounts and their own terms. Institution names in parser labels describe supported file formats, not endorsement or affiliation. Publishing this code grants no access to a banking provider or private dataset.
